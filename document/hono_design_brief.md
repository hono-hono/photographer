## 1. 目的とコンセプト

- 写真家 hono のブランドサイト。作品集ではなく、世界観と価値観が伝わるサイトにする。営業色は出さず、作品を主役にする。
- 目指す体験: 「写真集をめくるような静かな体験」
- 想定読者: 写真好き、写真業界関係者、写真メーカー担当者、将来展示や制作で関わる人
- 被写体: 廃線・廃墟・古い建物・人の面影を感じる風景
- デザインは被写体の雰囲気(廃墟・経年感)を直接まねない。honoさん自身の感性(無印良品・ユニクロ的なシンプルさ、北欧インテリアの落ち着き、柔らかいのに努力家)を出発点にする。
- 「一見主張がないのに、実は緻密」というギャップを、色ではなく書体・余白・動き・部品の形で表す。
- 避けること: 過度なアニメーション、パララックス、動画背景、派手なエフェクト、流行だけを追った表現。
- 技術: Next.js / TypeScript / App Router / コンポーネント設計 / レスポンシブ / GitHub管理。CMSは Kuroco、公開先は GitHub Pages。

## 2. サイト構成(決定)

3ページだけ。Profile と Contact は独立ページにしない。

| ページ | URL | 内容 |
|---|---|---|
| トップ | `/` | MV → 「すべての写真を見る」ボタン → Profile → Contact |
| Gallery | `/gallery?category=all\|works\|family\|anniversary` | 下層ページ。タブで絞り込み |
| 作品詳細 | `/gallery/[slug]` | Gallery の下層。写真だけを大きく表示 |

- ヘッダーのナビは **Gallery / Profile / Contact の3項目**。「Home」は置かず、ロゴを押すとトップに戻る。
- Profile と Contact は、トップ内の `/#profile` `/#contact` までスクロールする。Gallery・作品詳細からは `/#profile` `/#contact` でトップへ移動してから該当位置に進む。
- トップでは、いま画面にあるセクションのナビ項目に下線がつく。

## 3. 共通パーツ

- **ヘッダー: 画面上部に固定(決定)**。高さは PC 48px / SP 44px 程度。左にロゴ「hono」、右にナビ3項目。SPは右上に文字の「Menu」ボタン(アイコンなし)。押すとヘッダーの下に3項目が縦に並び、項目を選ぶと閉じる。
- ヘッダーの色・背景: 背景(#F7F7F6)と同じ色に、下端へ 1px の罫線(#D9D9D6)。スクロールで写真が下に回り込んでもロゴとナビが読めるようにする(2026-11-01 決定)。
- トップで Profile / Contact へ移動するときは、固定ヘッダーに見出しが隠れないよう、止まる位置を高さの分だけずらす。
- **フッター**: 1行。左に「© hono」、右に「Coconala ↗」(https://coconala.com/users/2362314、新しいタブで開く)。
- 余白の案: 左右 PC 64px / SP 20px、セクション間 PC 120px / SP 72px、基準単位 8px。

## 4. トンマナ(確定)

### 配色: 無彩色のみ
差し色は設けない。グレーの濃淡だけで状態(フォーカスなど)を表す。

| 用途 | 値 |
|---|---|
| 背景 | #F7F7F6 |
| パネル・入力欄 | #FFFFFF |
| 文字(主) | #1C1C1A |
| 文字(副) | #4A4A47 |
| 補助文字 | #8C8C89 |
| 罫線 | #D9D9D6 |
| タイル・ボタン背景 | #F1F1EF |
| 写真の仮置き | #B8B6B0 / #D9D9D6 / #8C8C89 / #4A4A47 |

### 書体
- 見出し・ロゴ: Noto Serif JP(レギュラー〜ミディアム)。字間は広め(ロゴ 14%、見出し 12%)。
- 本文・UI: Noto Sans JP(レギュラー)。行間は広め(本文 190%)。
- 目安のサイズ: ロゴ 22 / セクション見出し 24 / リード文(明朝)18 / 本文 14 / ナビ 13 / ラベル 12 / キャプション 11。

### 形と動き
- 写真は角丸なし、直角のまま。装飾しない。
- 丸みによる柔らかさは、写真以外の部品で出す。**案**: ボタンの角丸 10px(「すべての写真を見る」は薄いグレー #F1F1EF 背景、「送信」は #1C1C1A 背景に白文字)。入力欄は角丸なし。
- 写真のホバー演出は**なし**(クリックで遷移・拡大のみ)。
- 動きは最小限で一方向のみ(スクロールでの静かなフェードイン、ナビの下線が滑らかに伸びる、程度)。タブ切り替えと作品の前後移動に演出は入れない。
- 余白は写真集の版面のように広めに取る。

## 5. ページ別の仕様

### 5.1 トップ

1. **MV(メインビジュアル)**: 代表作10枚。
   - 「高さをそろえた行」で並べる。1行の中の写真は高さが同じで、幅は元の縦横比のまま。行の左右の端もそろう。Gallery と同じ並べ方で、同じ部品を使い回す。
   - PC は3行(4枚・3枚・3枚)、SP は5行(各2枚)。左右の余白の内側に収める(画面幅いっぱいにはしない)。
   - 写真の上に文字を重ねない。切り抜かない。
   - **写真を押すと拡大表示**(重ね表示で決定)。トップの上に暗い面を重ね、写真だけを大きく見せる。文字は出さない。前後移動はMVの10枚の中だけ(PC は写真の左右に矢印、矢印キー対応。SP は写真の下に Prev / Next)。閉じ方は「✕ 閉じる」、Esc、写真の外側を押す。閉じるとトップの元の位置に戻る。
2. **「すべての写真を見る →」ボタン**: MVのすぐ下、中央。`/gallery?category=all` に進む。**カテゴリ別のボタンは置かない**(決定)。
3. 一行ステートメントは**置かない**(決定)。
4. **Profile**(`#profile`)と **Contact**(`#contact`)は同じページの下に続く。→ 5.4、5.5。

### 5.2 Gallery(`/gallery`)

- タブ: All / Works / Family / Anniversary。選択中は下線。矢印キーで移動でき、ARIAの tablist / tabpanel パターンに対応。URLのクエリと連動する。クエリなしは all。
- 切り替えは演出なしで、瞬時に絞り込む。
- **写真は切り抜かず元の縦横比のまま**。1行の高さをそろえ、幅は写真ごとに変える。目安は PC 3〜4枚 / SP 2枚。キャプションなし。クリックで作品詳細へ。
- 各写真の幅と高さをデータに持たせ、読み込み中にレイアウトが動かないようにする。
- 作品詳細からブラウザの戻るで帰ったときは、選んでいたタブとスクロール位置を復元する。

### 5.3 作品詳細(`/gallery/[slug]`)

- **写真だけを大きく見せる**(決定)。タイトル・区分・年・撮影場所・撮影情報・「12 / 24」のような枚数表示は**載せない**。
- 写真は画面の高さに収まる大きさで、縦位置も横位置も切らず全体を表示する。
- 戻る手段は写真の上の小さな「← Gallery」だけ(元のタブとスクロール位置に戻る)。
- 前後の移動は、いま見ているカテゴリの中だけ。PC は写真の左右に矢印 + 矢印キー、SP は写真の下に Prev / Next。切り替えの演出なし。
- 写真の代替テキスト(画面には出ない短い文)は各作品に付ける。

### 5.4 Profile(トップ内)

- 配置: PC は左にポートレート(縦位置)、右に文章。SP は見出しの下にポートレート(横長)、その下に文章。**ポートレートは載せる**(決定)。
- 構成: 見出し「Profile」→ 明朝のリード文(1〜2文)→ 「写真歴」の本文 → 実績。
- **「被写体との向き合い方」と「人物像」は載せない**(決定)。
- 写真歴: **2013年から**撮影を始めた。
- **文面(2026-11-01 決定)**。文体は敬体
  - リード文(明朝): そこにいた人の気配や、営まれていた暮らしを想像できる風景に惹かれています。写真を見る人にも、その場所に流れていた時間を感じてもらえたらうれしいです。
  - 写真歴: 2013年に撮影を始めました。派手な絶景よりも、廃線や廃墟、古い建物に残された空気や物語を、静かに記録することを大切にしています。
- 実績(「時期・内容」の行リスト。区分ごとにまとめ、区分の中は新しい順。年月が分からない行は年月の欄を空ける):

  **受賞・選出**
  - 2025年5月 第63回 富士フイルムフォトコンテスト 最終選考通過
  - 2023年10月 若手写真家支援写真展 2023/2025 ファイナリスト(「2023/2025」は年度の表記。本番は「2023年度/2025年度」のように年度と分かる書き方にする案)
  - (年月なし)OM・新人写真家発掘プロジェクト・ライムライト ファイナリスト
  - (年月なし)第23回全動物写真コンテスト 準優秀賞
  - (年月なし)GANREF TODAY'S PHOTO 選出

  **講演・活動**
  - 現在 カメラのキタムラ写真教室 岡山版 現役アシスタント
  - 2023年12月 OM SYSTEM GALLERY 刻景 × 私の未来は(講演)

  **資格**
  - フォトマスター検定 2級

- 今後の実績追加に対応できるよう、行と区分を足すだけで済む部品にする。
- **載せないもの**: 展示歴・企画展・グループ展(師匠の経歴のため)。使用機材も載せない。

### 5.5 Contact(トップ内)

- 項目は3つだけ: お名前 / メールアドレス / お問い合わせ内容(自由記述)。問い合わせ種別の選択は設けない。
- 縦1列、ラベルは入力欄の上。幅は約480pxに絞る。冒頭に案内文「撮影のご相談や作品について、お気軽にお問い合わせください。」(決定)。
- 送信後はページ内の文面に置き換える(ページ移動なし)。入力ミスはその項目の直下に文章で伝える。
- 送信の仕組み: Kuroco のフォーム機能に送る(決定。詳細は `hono_component_design.md` 7.6)。
- フォームの下に連絡先のメールアドレス **photographer.hono@gmail.com** を文字で表示する(決定)。押すとメールアプリが開くリンクにする。フォームより目立たせない(補助文字の扱い)。

## 7. Figmaファイルの現状

## 8. 別の会話で作るもの(案)

PC(1440px)と SP(390px)の両方で、次の画面を作る。
1. トップ(ヘッダー、MV、ボタン、Profile、Contact、フッター)
2. 拡大表示(トップの上に重ねた状態)
3. Gallery(タブ + 高さをそろえたグリッド)
4. 作品詳細(写真だけ)

提案するときは、なぜその提案なのか、コンセプトとのつながり、ユーザー体験への影響まで説明する。改善案や別案があれば遠慮なく出す(要件定義の依頼方針どおり)。
