## ステップ2　写真と文章をそろえる 🙋

> 💡 **方針（2026-11-01 決定）**
> 写真は当面**ダミー画像**で進める。縦位置・横位置・正方形など縦横比の違う灰色の画像を使い、デザイン・Kuroco・実装をそのまま進められるようにする。実際の写真は公開前（ステップ7の確認まで）に Kuroco 上で差し替える。

- [ ] 🤖 ダミー画像を用意する（作品20枚程度＋ポートレート1枚。縦横比はばらばらにする）
- [ ] （公開前まで）MVに使う代表作10枚を選ぶ
- [ ] （公開前まで）Gallery に載せる写真を選び、Works / Family / Anniversary に振り分ける
- [ ] （公開前まで）写真を書き出す（長辺3000px程度までのJPEG。サイト用の縮小は自動）
- [ ] （公開前まで）各写真の代替テキスト（画面には出ない短い説明）を書く
- [ ] （公開前まで）ポートレート写真を用意する（PCは縦位置、SPは横長で切り抜いて表示）
- [x] Profile のリード文と「写真歴」の本文（2026-11-01 決定。文面は仕様書 5.4）
- [x] お問い合わせの案内文と、自動返信メールの文面（2026-11-01 決定。文面は仕様書 5.5）
- [ ] ココナラのプロフィールの撮影歴「約5年」を「2013年から」に直す

> ⚠️ **注意**
> 公開するのは、写っている人の了承が取れている写真だけにしてください。特に Family / Anniversary の写真が対象です。

## ステップ5　サイトを作る 🤖

設計書 12章の順番で進めます。今リポジトリにある部品（`Hero`、`FeaturedGallery` など）は、設計の構成に組み替えます。

1. [ ] 土台（デザイントークン、フォント、共通の枠）

3. [ ] Gallery（高さをそろえた並び、タブでの絞り込み）
4. [ ] 作品詳細、トップの拡大表示、MV
5. [ ] ヘッダー、SPメニュー、フッター
6. [ ] Profile、Contact（Kuroco フォームと接続）
7. [ ] フェードイン、404ページ、各ページのタイトルと説明文

> 💡 **補足**
> 作業ごとにプルリクエストを作り、確認してから `main` に入れます。`main` に入った時点で自動公開が動くので、ステップ6までは公開の設定をオフのままにしておけば安全です。

## ステップ6　公開の設定をする 🙋🤖

- [ ] 🙋 リポジトリの Settings → Secrets に Kuroco のAPIトークンを登録する（`KUROCO_API_TOKEN`）
- [ ] 🤖 自動公開のワークフローに「Kuroco で更新したら再公開する」きっかけを足す
- [ ] 🙋 Kuroco の外部システム連携で GitHub と接続する
- [ ] 🙋 **リポジトリの Settings → Pages で、Source を「GitHub Actions」にする**（これで公開される）

> ⚠️ **注意**
> Pages を有効にした時点で、`main` の内容が誰でも見られる状態になります。仮の画像のままのサイトを見せたくなければ、ステップ5が終わるまで有効にしないでください。
